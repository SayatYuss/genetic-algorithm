# Оптимизация логистики (VRPTW) с использованием Генетического Алгоритма

Этот проект представляет собой решение задачи маршрутизации транспорта с временными окнами (**VRPTW** - *Vehicle Routing Problem with Time Windows*) с использованием эволюционных вычислений.

Алгоритм распределяет заказы по грузовикам, минимизируя общую дистанцию и количество используемых машин, при этом строго соблюдая временные окна клиентов (часы работы) и грузоподъемность транспорта.

## Возможности

* **Генетический алгоритм:** Использование библиотеки `GA` для поиска субоптимального решения в огромном пространстве вариантов.
* **Реальная картография:** Расчет дистанций и времени пути по реальным дорогам с помощью **OSRM API** (Open Source Routing Machine).
* **Жесткие ограничения:**
    * Учет грузоподъемности (`Capacity constraint`).
    * Учет временных окон (`Time Windows`): прибытие, ожидание, обслуживание.
    * Минимизация автопарка.
* **Интерактивная визуализация:** Генерация карты маршрутов с помощью `Leaflet`.
* **Генерация данных:** Python-скрипт для создания датасетов и симуляции заказов.

## Технологический стек

* **R** (Ядро алгоритма):
    * `GA` — реализация генетического алгоритма.
    * `osrm` — построение матриц расстояний и времени.
    * `leaflet` — визуализация результатов.
    * `dplyr` — манипуляции с данными.
* **Python** (Подготовка данных):
    * `pandas` — генерация CSV с параметрами заказов.

## Установка и запуск
1. Предварительные требования
    - Убедитесь, что у вас установлены R и Python.

2. Установка зависимостей
    * Для R: Выполните следующие команды в консоли R:
    ```R
    install.packages("GA")
    install.packages("osrm")
    install.packages("leaflet")
    install.packages("dplyr")
    install.packages("htmlwidgets")
    ```
    * Для Python
    ```bash
    cd create-dataset
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    ```
    Для генерации новых данных нужен файл (`coords.csv`) с координатами в `data/`

## Запуск алгоритма
Откройте файл main.R в RStudio. Скрипт разбит на логические блоки:

* Блок 1-2: Загрузка библиотек и данных, расчет матриц OSRM.

* Блок 3: Определение Фитнес-функции (логика штрафов).

* Блок 4: Запуск обучения Генетического Алгоритма.

* Блок 5: Построение интерактивной карты (Leaflet).

* Блок 6: Вывод текстового логистического расписания (Manifest).
